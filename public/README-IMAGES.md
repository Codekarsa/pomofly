# Required SEO Images

To complete the SEO setup, add the following images to the public/ directory:

## OpenGraph Image
- **File**: `og-image.png`
- **Size**: 1200x630 pixels
- **Purpose**: Social media sharing (Facebook, LinkedIn, etc.)
- **Content**: Pomofly branding with app preview

## Twitter Card Image  
- **File**: `twitter-image.png`
- **Size**: 1200x630 pixels (or 1200x675)
- **Purpose**: Twitter card display
- **Content**: Similar to OG image, optimized for Twitter

## Favicon (if needed)
- **File**: `favicon.ico`
- **Size**: Multiple sizes (16x16, 32x32, 48x48)
- **Purpose**: Browser tab icon

These images will be automatically referenced by the meta tags in the layout.
